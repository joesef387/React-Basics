# React Assignment Projects

This repository contains two independent React projects:

- `my-react-app` — Student Registration App
- `my-blog-app` — Pulse Blog App

Each app has its own dependencies and can be run separately.

## Student Registration App

```bash
cd my-react-app
npm install
npm run dev
```

## Pulse Blog App

```bash
cd my-blog-app
npm install
npm run dev
```

Run `npm run build` or `npm run lint` from either project folder to build or check that app.
